1. เหตุผลที่อยากเรียน Full Stack Web Development

   ต้องการเข้าใจการพัฒนาเว็บทั้งหน้าบ้าน (Front-end) และหลังบ้าน (Back-end) เพื่อให้สามารถสร้างแอปพลิเคชันได้ครบวงจรด้วยตัวเอง และต่อยอดทักษะให้ทันเทคโนโลยีในสายงาน IT

2. ความคาดหวังต่อวิชานี้

   มุ่งหวังที่จะเรียนรู้โครงสร้างระบบการเชื่อมต่อ API และฐานข้อมูล พร้อมทั้งฝึกทำโปรเจกต์จริงเพื่อเพิ่มทักษะการแก้ปัญหาที่นำไปใช้ในการทำงานได้ทันที IT

3. จุดอ่อนที่ต้องพัฒนาเกี่ยวกับทักษะ Programming และแนวทางการพัฒนา

  • จุดอ่อน: สับสนเมื่อเจอ Logic ซับซ้อน และใช้เวลานานในการแก้ข้อผิดพลาด (Debug)

  • แนวทางการพัฒนา: ฝึกทำโปรเจกต์อย่างสม่ำเสมอ ศึกษาเครื่องมือ Debugging เช่น Chrome DevTools และฝึกวิเคราะห์โค้ดอย่างเป็นระบบมุ่งหวังที่จะเรียนรู้โครงสร้างระบบ
